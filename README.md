## Overview

An **interactive browser-based 3D scene** that lets you dynamically add and explore 3D geometric objects — Cubes, Spheres, Cones, and Toruses — rendered in real time using **Three.js**. Built with pure HTML, CSS, and JavaScript; no frameworks or build tools required.

---

## Features

- **Dynamic Object Creation** — add Cubes, Spheres, Cones, or Toruses with one click
- **Full Orbit Controls** — rotate (left-click), zoom (scroll), and pan (right-click)
- **Clear Scene** — reset and start fresh instantly
- **Lightweight** — no npm, no build step; just open in a browser
- **Responsive Canvas** — fills the full viewport

---

## Getting Started

```bash
git clone https://github.com/Qaiser-baitham/3d-objects-demo.git
cd 3d-objects-demo
```

Open `index.html` in any modern browser — done!
